# Contributing to Egyptian Humanizer 2027

Thank you for your interest in contributing to **Egyptian Humanizer 2027**! We welcome researchers, computational linguists, full-stack engineers, and Arabic NLP practitioners from across the globe.

---

## 🌟 How to Contribute

### 1. Reporting Bugs
- Search existing issues to ensure the bug hasn't already been reported.
- Open an issue using the **Bug Report** template.
- Provide a minimal reproducible example (including the input text and unexpected output).

### 2. Suggesting Enhancements & Stylistic Lexicons
- We are always expanding our academic lexicon, rhetorical connectors, and discipline-specific terminology (Economics, Law, Medicine, Social Sciences, Computer Science).
- Open an issue using the **Feature Request** template to propose new rhetorical modules or stylistic paradigms.

### 3. Pull Requests
1. Fork the repository on GitHub.
2. Create a clean feature branch: `git checkout -b feature/academic-lexicon-expansion`.
3. Commit your changes with descriptive, professional messages:
   ```bash
   git commit -m "feat(engine): add 45 transitional academic connectors for legal discourse"
   ```
4. Ensure all syntax checks pass:
   ```bash
   python -m py_compile server.py engine.py db.py security.py
   ```
5. Push to your branch and submit a Pull Request.

---

## 📜 Code of Conduct
- Maintain absolute academic objectivity and scientific rigor.
- Respect the sovereign privacy standards of the engine (no telemetry, no external trackers, no secret logging).
- Foster a respectful and inclusive collaborative environment.
